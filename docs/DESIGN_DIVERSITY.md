# DESIGN DIVERSITY ENGINE

## Regla

No basta con cambiar colores.

Dos proyectos deben poder tener:

- diferente información jerárquica;
- diferente navegación;
- diferente hero;
- diferente proporción de espacios;
- diferente densidad;
- diferente sistema de tarjetas;
- diferente tratamiento de imágenes;
- diferente CTA;
- diferente ritmo vertical.

## Arquetipos

### commerce
Catálogo, categorías, producto destacado, carrito/CTA.

### restaurant
Experiencia, menú, platos destacados, reservas, ubicación.

### hotel
Destino, habitaciones, amenities, booking CTA, galería.

### saas
Problema, producto, dashboard, features, prueba/demo.

### portfolio
Trabajo destacado, proyectos, biografía, contacto.

### agency
Manifiesto, servicios, casos, proceso, clientes.

### event
Fecha/lugar, lineup/agenda, tickets/registro.

### product
Objeto protagonista, storytelling, especificaciones, compra.

## Dirección

La dirección visual modifica tokens y composición:

- editorial
- minimal
- bold
- luxury
- playful
- brutal

El objetivo es evitar el patrón único `hero + 3 cards`.
