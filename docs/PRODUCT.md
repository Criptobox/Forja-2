# FORJA — PRODUCT SPEC

## Experiencia principal

El usuario escribe una frase.

Ejemplo:

> Una pizzería artesanal con temática de Halloween.

FORJA decide automáticamente:

- dirección visual;
- arquitectura de página;
- contenido;
- componentes;
- imágenes;
- responsive;
- herramientas;
- modelo/proveedor;
- QA;
- correcciones.

El usuario recibe una web real.

## No convertir FORJA en un chat genérico

El chat puede existir como interfaz de control, pero el producto es el sitio web terminado.

## Resultado

```text
BRIEF
→ DIRECCIÓN
→ PLAN
→ DISEÑO
→ CÓDIGO
→ PREVIEW
→ QA
→ REFINAMIENTO
→ WEB TERMINADA
```

El usuario debe poder:

- ver preview;
- inspeccionar proyecto;
- conectar GitHub;
- descargar ZIP.
